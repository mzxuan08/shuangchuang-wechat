# 三种核心能力的包内对应

本包默认执行内部规则，不要求安装原三个技能。所有写法均服务团队公众号用途，原技能的论文、自媒体或其他领域示例不改变母技能范围。

| 来源能力 | 包内实现 | 使用时机 |
| --- | --- | --- |
| anti-defensive-writing：围绕真实优势，明确贡献、控制比较范围，必要时重建叙事 | [价值叙事与反防御](anti-defensive.md) 的主线与结构 | 新写、获准重写 |
| anti-defensive-writing：不按过程流水账，不自我削弱，不把弱项当主战场 | 主技能的成果前置、后台核查与干净交付；反防御中的语言规则 | 全程，受编辑范围约束 |
| anti-defensive-writing：实验服务论证、按职责选择证据；结尾强化贡献 | 反防御的证据选择、弱材料决策和内部复扫 | 项目进展、成果与深稿 |
| lieflat：11类可定位触发规则、最小改动、结构与信息守恒 | [完整白名单规则](upstream/lieflat-less-ai-tone/rules.md) 与 [编辑引擎](editing.md) | 轻清理 |
| qu-ai-wei：信息账本、论证关系、八个模式族、全文重建、全局复扫 | [完整重写规则](upstream/qu-ai-wei/rules.md)、[模式目录](upstream/qu-ai-wei/references/pattern-catalog.md) | 普通改稿与重写，幅度按授权区分 |
| qu-ai-wei：保护声口、引语、事实强度；凭证门检、素材指令隔离、内嵌模式 | 编辑引擎与包内完整规则 | 编辑与交付 |

lieflat 的11类为翻案腔、过密顿号并列、相邻句同构、破折号、提示性冒号、通篇小标题序数、理想化职业拟人、已有数据恢复、禁用起手式、五种指定翻译腔、段首零主语评论。完整触发与例外以包内原规则为准，不扩大白名单。

qu-ai-wei 的八族覆盖内容真实性、证据强度、篇章组织、中文句法、词汇与语义复现、修辞节奏、受众平台、来源引用。全文先冻结信息，再重建阅读顺序，最后核回账本；不通过“换几个词”冒充完成。

普通改稿使用 qu-ai-wei 的保义方法，不将 lieflat 的窄权限推广到全部修改任务。lieflat 的完整白名单及原规则保持不变，明确选择严格轻清理时照常执行。模式选择见 [编辑引擎](editing.md)。

## 冲突怎样裁决

事实真值、范围与用户编辑授权优先。反防御决定突出什么，不能改写事实；轻清理保留结构，不能套用重写的宽权限；重写可调结构，不能同时宣称未命中句子逐字不动。只保留原始必要的限制，不增加无来源的负面评价。

文稿已有“未超过某基线”的实质结果时不删掉事实；新写稿只聚焦别的有依据价值时不必主动展开无关指标。样本、使用阶段或法规要求若决定读者是否会被误导，仍自然写清。去掉自我削弱不等于取消这些条件。
