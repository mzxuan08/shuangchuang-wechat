# 多项目与连续进展怎样写

适用于多项目活动、合作后续报道和多项学术成果稿。新写、常规编辑及获准重写时按需要使用；严格轻清理不借此重排原稿。对应来源见 [扩展样本](expanded-sources.md) 的N47—N57。

## 先找到这一次的新闻落点

先用一句话回答“本次新发生了什么”。可选一次具体合作推进、一项正式结果或新的专业交流内容，不必把活动所有材料同时放进导语。哪项先写取决于用户的报道目的及信息分量，不能自动认定金额最大、职务最高或最成熟的项目必须占主位。

新写活动稿可以详写有内容的项目，其余按真实主题或阶段归并；只给题名时，可交代整体展示范围，不从题名补出方法与效果。用户要求逐项完整介绍时逐项保留；常规修改与重写仍保护已有独立事实、实质评价及限定，不为了主次丢掉其他项目。

N47没有把每个项目展开，而以集体展示及实际讨论收束；N49区分详述的专题讲座与各篇论文；N54由总量进入代表团队。三者说明不同材料可以选择不同详略，不是固定的“重点一项、其余略过”模板。

## 旧合作解释来由，本次动作承担推进

参考N48、N53。旧协议、既往到账和此前应用提供背景，本次报道交代又做了哪一步：讨论技术条件、确定某项分工、完成新验证或签署具体合同。用时间词和行动者自然区分，让读者看见变化。

例如“4月已签框架协议，本次讨论耐水测试分工”有真实推进，但尚未确定测试安排时，不能写成“测试启动”或“合作机制落地”。本次只有讨论也可报道讨论内容，不必把此前的成果重复算作新增。计划中的下次活动属于原页面当时的计划，学习旧报道时不推断今天是否已经完成。

## 每个数字跟着自己的对象与阶段

内部核对时把数字与对象配对，成稿中只保留帮助理解的数字和必要条件，不输出核查清单。

| 材料中的数字 | 成稿对应的事实 |
| --- | --- |
| 展示12项，其中8项路演、4项海报 | 共12项，不把其中8项另加一次 |
| 5万元技术开发合同，款项未到账 | 合同金额与收款状态同时成立，不写成获得5万元收入 |
| 全校年度合同总额 | 保留学校、年度及截至时间，不改成某次活动或本团队收入 |
| 共同署名3人，1人作报告 | 作者与汇报人分别对应，不写3次发言 |
| 三等奖、口头报告与科普展演 | 各自对应正式名称与形式，不统称三项大奖 |

N48、N51、N54、N55分别提供了这些区分的写法参考。这个表只帮助识别关系，不要求每篇都包含全部类型，也不授权补齐缺少的记录。题名或报告中的技术效果按原归属处理，不能把名称本身当成新证据。

## 年度总结：项目、项目次与成果各有口径

参考 N84。年度总结按实际贡献归类，选择能说明变化的项目；往年启动、当年推进和下一年计划各归所属时间。同一个项目参加多场赛事，属于多次参赛，不变成多个项目。全年总量与其中一次活动、累计数据与当年新增也不能重复相加。

反馈条数不自动改成人数，浏览量不改成使用者数；缺少去重关系时保留原单位，不猜总人数。多项目可用共同维度交代对象、做法与阶段，仍保留每项不同的奖项、成员和进度，材料多寡决定详略。统计核查放在内部，正文呈现必要口径，不另写自我审查段。

## 专业内容承接主线，不写成名单流水账

多项成果可以按同一尺度组织：同场会议按交流形式，多场会议按研究问题，后续报道按不同项目本次推进的阶段。一个单元内保留题名、负责人和必要状态，让每段提供不同信息；已有真实报告内容时再解释方法与应用对象。

共同点评没有逐项目对应，就作为共同交流内容交代，不擅自把某条意见分配给某个团队。保留来稿中的老师、教授等称谓。论文作者、实际汇报人、主持人、专委会委员和团队负责人分别识别，不因同段出现就互换身份。

## 在最后一个有信息的内容处收住

材料最后是专家围绕接口适配、使用习惯与验证范围点评，稿件可以停在这项已发生的交流。没有确定的下一步，无须转而列“合作分工如何确定、技术开发如何推进”等作者代拟的问题，也不另加“尚不能说明真正落地”的自我审查。

“这些问题把关注点从展示带向使用”“推进感体现在逐项回答问题中”等旁白，如果只是替前文解释其意义，可以省去，让实际动作承担推进。有真实的研究问题、采访原问、专业解释或作者有依据的判断时仍保留，不把问句和评价一概删除。

N47收在真实互动，N56交代专业交流内容，N57以共同临床问题串联不同成果。学习这种信息衔接；原文重复的开头、对称升华和泛泛赞誉不用跟着复制。
