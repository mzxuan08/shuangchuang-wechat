# 价值叙事与反防御

本文件将用户提供的 anti-defensive-writing 核心原则改写为团队公众号工作方法。全文为场景化整理，未随包复制原技能全文；论文实验组织映射为报道的证据选择，不把公众号变成论文。

## 主线：真实价值站到前面

先找最有分量的一项：解决了一个具体需求，形成新方法或新能力，在某个有意义的约束下节省时间、降低成本，完成真实应用，或取得正式认可。按已有证据选择，而不是按材料排列顺序写。

给读者一条成立的叙事：问题为什么值得做，团队采用什么关键做法，结果在哪个范围内有价值。材料没有现有方法的比较，就不补写“传统模式弊端”；没有效果结果，就报道已经形成的能力和阶段成果。

先确立优势，再选择评价维度。速度不领先但成本有优势且材料有依据，可以围绕成本与目标场景组织；不把“不领先速度”当标题，也不偷偷改变同一指标的统计口径。真实权衡只在素材说明目标或约束时成立，不替失败发明理由。

## 语言：减少自我削弱

新稿优先采用带行动者和结果的肯定陈述。减少没有信息的“仅仅”“只是”“还远远不够”“遗憾的是”“与成熟方案仍有较大差距”；不机械禁用单字“仅、尚、初步”。

| 写法 | 如何处理 |
| --- | --- |
| “团队只是完成了一个初步原型，尚不能说明实际价值。”素材未作这个判断 | 写出已完成的原型及已有验证；不新增否定性评价 |
| “仅纳入10名学生的内部测试” | 自然写成“在10名学生参与的内部测试中”，保留人数与范围 |
| “本项目只适用于……”原文是明确适用边界 | 保留限制，可改成“适用范围为……”，不扩大对象 |
| “尚未开展院外试点”但全文只报道校内展示 | 新写稿可不单独设此提醒；“内部测试”“实训试用”须准确 |
| 原稿明确记录某指标下降或一次失败 | 编辑时保留事实；可在获准重写后安排到相应结果与解释处，不改成成功 |

“降防御”改变表达重心，不改变事实真值。不要让每项成果后面都跟一段限制；必要条件直接写进对应结果句，比先夸后撤回更清楚。

## 证据：每一项承担不同职责

从已有材料中选择：

- 结果证据：核心变化、完成事项、正式奖项或应用记录。
- 机制证据：关键做法怎样带来这一结果，材料有没有支持。
- 场景证据：目标使用者、条件和实际用途，避免泛泛说有价值。
- 排除解释：素材确有对照或验证时说明，不能临时补造实验。

短讯有一两类证据就能成篇。深稿可把主结果放前，再补关键机制和场景；图表、案例和引语各自提供新信息，不充当结果仓库。一个弱项与主张无关时，新稿不主动开辩论；确实反驳主张时，缩小或重建主张，不能藏掉使结果失真的事实。

## 结构：开头建立贡献，结尾强化记忆

标题与导语优先给出事件及最强成果；正文解释做法与证据；结尾回到本次解决的具体问题、形成的能力或有材料的后续工作。不从实现细节和尝试过程写起，不在末段突然加新的自我否定。

素材支撑不了最初想讲的故事时，重选主线：例如从“全面应用成效”收缩到“原型完成及内部验证”，保留该阶段已经成立的价值。用户要改标题或全文重写时可调整信息架构；用户只准轻清理时保持结构，另行说明真正需要授权的调整。

## 遇到弱材料的选择顺序

新写稿依次尝试：选出相关事实；缩小主张；选择有依据的价值维度；说明材料中真实存在的目标差异或权衡；重排证据；重建主线。只有无法回避且影响核心结论时才作必要说明。编辑现有稿件时，这套顺序不授权删除独立事实。

当材料只有报名或交流记录，报道其事实即可，不强造“突破”；有试验结果就把范围和结果写清，也不主动加“因而仍须谨慎”等无关评价。

## 内部复扫

开头是否已经出现本次成果？最强证据有没有被背景淹没？是否重复讲过程而不解释贡献？是否替读者设置了无人要求的质疑？是否把某一弱项扩大为整体评价？有没有新增不必要的免责段？结尾是在强化贡献，还是突然否定前文？

复扫留在内部。用户要正式推文时，给推文；不默认输出这份检查表。
