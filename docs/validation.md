## 2.6.0 · 团队视角与可复核交付

2026年10月24日。新增12篇已读正文的团队、双创及赛事报道，扩展样本累计77篇，连原六篇共83篇。其中5篇能由转载页确认公众号来源，正文通过转载页读取；微信直链未直接打开的情况据实记录。另有1篇只在赛事背景引用微信，不作为整篇公众号转载。N77未见完整日期，留空。未取得正文的候选排除，原稿全文与图片不分发。

新增团队账号选题与成稿指南，处理参加者稿照搬主办方通稿的问题。学习落到标题主语、事件与项目的篇幅、段落推进和改稿落实；既有三套能力、老师称谓与严格清理范围保持。

本轮可见行为证据见 [8题题包](evaluation-cases.md)：同一素材的团队与组织方视角、薄材料普通修改、真实引语的严格清理、成本优势与负面结果、省赛奖与其他队奖项、素材命令隔离。每题公开输入、当前模型输出与人工核对。T5曾出现校核与卡扣修改的归属含混，已修订；T6曾增加未经给定的“此前”，已撤销，指南补充合句时保护主语及时间关系，并用T8的新素材复核。它们说明初稿仍需全文事实复核，不能用规则数量替代验收。

另以用户此前提供的座谈原稿作本地实稿验收，保留两位老师、三方信息、业务板块、具体建议及后续方向，改善目的导语和重复收尾；原稿和本地成稿不进入公开库。此轮由维护者当前模型试写并人工对照，未作独立盲测或受控无技能比较，未调用DSH、WorkBuddy自身模型。不报告虚构的提升比例。

构建校验结构、样本及批次、两种包、链接和上游规则哈希；这些是发行质量检查，与写作验收分别记录。

## 2.5.0 · 专业解释、短讯与人物长稿

2026年10月23日。本轮新增8篇已读取正文的高校报道，扩展样本累计65篇，连同原六篇共71篇。N62为2021年历史写法样本，保留页尾日期；它的行业判断不作当前依据。未读到正文的候选不计入，文章全文与图片不随包分发。

新增“专业内容与人物声音”指南，覆盖代表项目选择、技术与使用动作的连接、长稿中的设计选择、不同人物的信息职责、真实引语及小标题。保留三套能力和既有编辑范围，不把新写法扩大为严格清理权限。

本轮由维护者完成五题虚构素材试写，再按输入逐项人工对照。没有把此次维护者试写称为独立Agent测试，也未调用DSH或WorkBuddy自身模型。

| 场景 | 对照结果 |
| --- | --- |
| 活动短讯 | 15项成果与6项口头汇报、9项壁报分别对应；选一个项目说明研究对象、设计与提纲，未补调查结果或推定它的展示形式 |
| 技术进展 | 设计动作接到接头固定问题，保留8千克20轮中1轮松动、12千克测试未完成与拟校内试用，没有另写免责段 |
| 师生侧记 | 4名学生的建模、装配、供应商联系与采购清单分工对应，老师原话保留；初稿重复调整轮次和指导内容，经人工复核精简后保留全部事实及续航未达标状态 |
| 两段常规修改 | 事件前置，压合重复意义；两段、老师称呼、原话、重要参考评价及时间未定事实保留 |
| 严格轻清理 | 无规则命中时全文原样返回，不因默认输出格式添加标题或解释 |

上述检查说明这些试写的事实和编辑范围对应情况，不证明任意模型的通用写作效果。构建继续核对单入口、相对链接、样本与批次、两类包正文一致性及上游规则哈希。

## 2.4.0 · 多项目与连续进展

2026年10月23日。新增11篇已读取正文的高校、医院报道及医院名下账号文章，扩展样本累计57篇，连原六篇共63篇。正文未读到的候选不计入；N50经公开页面直接读取补全，N53为媒体报道的官方转载，N57按医院账号文章记录而非平台独立采访。各卡片保留来源、日期、阅读状态、组织方法与迁移边界。

修改前，独立 Agent 使用2.3版处理虚构的第二期项目对接会素材。它已经能区分旧协议、新合同、未到账及拟试用，准确保留引语；末段则以旁白解释点评意义，并代拟“合作分工如何确定”等问题收尾。本次补充针对多项目主次、旧事与本次动作的衔接，以及收在真实内容上的方法，没有把基线描述成事实全面错误。

修改后，另一独立 Agent 只读本包、不联网，完成四题：

| 场景 | 观察结果 |
| --- | --- |
| 连续合作与多项目展示 | 12项展示中的8项路演、4项海报未重复相加；旧框架协议、新5万元合同及未到账、本次测试分工讨论、秋季拟试用分别保留，2025年度服务企业数不记为本场成果，末段收在共同点评内容 |
| 混合学术成果 | 专题报告、共同署名论文的实际口头报告人、壁报及讲解类三等奖分别对应，未统称同级奖项 |
| 两段常规修改 | 保留周老师及原引语、后续试验时间未定的事实，处理同义意义句，维持两段 |
| 严格白名单 | 原首末句保留；初试在默认标题提示下多加了标题，母流程补充原文形式保护，再作独立回归 |

新独立 Agent 的三题回归确认：白名单题无新增标题且首末句逐字保留；纯校对题无错字则原样返回；新写题正常交付标题与简讯，保留原型及拟试用阶段。输出格式的默认值不再覆盖严格编辑的具体限制。相关逐字保护项已人工对照。

这些试写验证上述场景中的范围与信息对应，不等于跨模型的统一质量评估。两套完整上游规则快照、反防御改编及2.3版编辑模式保持；本轮未调用DSH、WorkBuddy自身模型。

## 2.3.0 · 普通改稿与严格清理分开

2026年10月23日。根据实际改稿反馈修正默认路由：普通“改一下、润色、顺稿”采用保义编辑，不再自动等同于白名单轻清理。指定lieflat、未命中逐字不动、只校对、只恢复称呼等限制继续执行。材料有限时完成已有事实能够支持的稿件，改动说明依据真实差异。

修改前，独立 Agent 使用2.2版处理虚构商会座谈稿的普通修改请求。它依据旧版路由明确选择轻清理，仅调整四处列举及一处名词化表达，长目的导语与重复收尾保留。该结果复现了路由过窄的问题。

修改后，另一独立 Agent 只读本包、不联网，完成六项试用：

| 场景 | 观察结果 |
| --- | --- |
| 普通“改一下”，没有更多信息 | 以日期、主体、座谈事件开头，保留三方内容与老师称谓，合并意义和后续段，未要求补案例或增加协议 |
| 指定白名单轻清理 | 两段与未命中句子保留；初次对翻案腔的处理仍留下否定换壳，另作修复及回归，见下文 |
| 润色但保留结构 | 标题、六段数量与顺序、署名保留，句内处理导语和重复表达 |
| 薄材料新写简讯 | 保留3名学生、原型和下学期拟试用阶段，未增加效果、评价或补充资料要求 |
| 只恢复两处老师称呼 | 只插入两处“老师”，其他文字相同 |
| 询问前后改动 | 准确说明只将一处顿号换为“和”，未宣称重构全文 |

首次严格清理把翻案句换成“交流开启，合作没有终止”，仍保留了多余否定解释。母流程补充按lieflat原规则直接正面表达、逐项重新选择范围，未改上游快照。再由新独立 Agent 完成四项回归：两段白名单稿直接写“座谈是持续交流的起点”；另一题保留“只适用于校内教学、尚未院外试用”的实质边界；纯校对题无错字则原样返回；普通润色题仍能前置事件、合并重复。相应逐字保留项已人工对照。

本轮另新增12篇已读取正文的高校报道，扩展样本累计46篇，连原六篇共52篇。卡片同时分析可借鉴方法与重复结尾、称谓不一致等不沿用事项；未读到正文的候选不计入。测试结果仅对应上述场景，未调用DSH、WorkBuddy自身模型；三套能力和包内上游规则继续保留。

2026年10月23日。

独立 Agent 只读取本技能目录，不允许读取本机其他技能或联网。在这一条件下完成了四项试用：

| 场景 | 观察结果 |
| --- | --- |
| 新写：工具原型、内部测试与实训试用安排 | 标题突出用时变化；保留10名学生、三轮120次、40秒至26秒、内部测试及拟试用范围；未附“未获奖、未院外试点”的无关自我审查段 |

构建校验可用标准 Python 执行：

```sh
python tools/build.py --check-only
python tools/build.py
```

发行包采用固定 ZIP 时间戳，构建结果可复现；校验覆盖所有包内 Markdown 链接、单一技能入口、两种元数据、包内上游快照哈希、公开路径清理和 ZIP 内容。原始新闻文件、机器路径、账号凭证、会话记录和本机其他技能均不在发行包中。
