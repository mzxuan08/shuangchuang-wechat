# 实际写稿场景题包

2026年10月24日，2.7.0版新增12题。与 [此前8题](evaluation-cases.md) 合计20题。素材均为虚构；真实文章只用于学习写法，不冒作这些项目的证据。

先保存12题输入，再由维护者当前模型完成试写及逐题复核。P4使用与P3相同的事实底稿，分别给出学生与单位版本。本轮没有另调独立Agent、没有无技能对照，也没有在DSH、WorkBuddy自身模型中写稿；不能由这些样例推算跨模型效果。输入、成稿与复核判断一同公开，读者可复制输入重测，比较事实与任务完成情况，不要求字句相同。

## 重点核对

优先检查结果是否升级、角色是否错位、独立负面结果是否保留，以及修改是否越权。招募和预告还要检查条件、截止时间与确认状态；年度稿检查项目数和项目次；同素材面向不同读者时检查事实是否一致。语气、衔接与篇幅由编辑读全文判断，文件构建通过不等于这些判断自动成立。

## 本轮用途与后续验收

12题覆盖喜报、年度总结、学生与单位两种读者、招募、预告、答辩、侧记、压缩、局部编辑、延期及并行活动。它们提供实际成稿和事实核查证据；仍属于维护者当前模型的场景演练，真实写稿时需按原素材复核。新版将参与条件、读者重心与统计单位的写法补进原有指南，没有给每种题型再加一套必填结构。
