# 可复核试写题包

2026年10月24日，2.6.0版。用于判断技能能否完成实际写作任务。下列素材均为虚构，不是学习来源中的真实项目。输入、交付样例与核对项分开列出，读者可以自行检查，也可只复制输入，在自己的宿主新对话中复测。

本轮样例由维护者所在的当前模型写出并逐项复核；不是独立盲测、没有与无技能模型作受控比较，也没有调用DSH或WorkBuddy自身模型。它能展示具体交付及发现的问题，不能仅凭样例宣称跨模型提升比例或替代实际编辑验收。

## 怎样判断确实可用

先检查任务与事实：账号视角是否正确，要求保留的信息是否仍在，角色、奖项、数字、时态是否对应。再读全文：标题能否由正文兑现，项目是否讲得明白，段落是否推进，重复是否已处理。不同模型可以有不同措辞，不要求照抄样例。

硬性失败包括：把展示写成获奖、把试用计划写成效果、删掉独立负面结果、改变原话或老师称谓，以及越过局部修改范围。句式不漂亮或有轻微重复则记录具体位置，修改后复核，不能用自动关键词命中数冒充文笔评分。

## T1：团队号，活动作为场合

### 输入

用本技能为星桥团队公众号写短讯，可按团队主线选择素材，只给标题和正文。10月12日，学院举办青创展示会，共20个项目，其中12项口头汇报、8项壁报。星桥团队作壁报展示，展示的是用于区分相近名称材料的标签装置原型。团队5名成员中3人到场，2人留校整理测试记录。郝老师指导标签固定设计。校内20轮测试中19轮标签保持固定，1轮松脱。团队计划下学期在校内实训中试用。

### 交付样例

星桥团队展示标签装置原型，交流材料辨识与固定设计

10月12日，星桥团队在学院青创展示会上作壁报展示，介绍用于区分相近名称材料的标签装置原型及标签固定设计。郝老师指导设计工作，团队5名成员中3人到场交流，2人留校整理测试记录。

在校内20轮测试中，标签有19轮保持固定、1轮出现松脱。团队计划下学期在校内实训中试用该原型。

### 核对

团队及装置进入标题和导语；壁报没有升级为奖项。5名成员、3人到场与2人留校各有归属，老师指导与测试状态保留。全场20个项目不是本队成果，可在团队短讯中不展开。拟试用没有提前写成应用效果。

## T5：有优势也保留独立负面结果

### 输入

写一篇项目进展，突出成本优势，保留全部事实。启程团队10月8日展示可拆卸支架原型；同一尺寸下材料成本500元，对照方案900元。李老师指导结构校核，3名学生完成卡扣修改与台架复测。8千克载荷下20轮中1轮接头松动；12千克载荷测试尚未完成。团队计划下学期在校内实训试用。

### 交付样例

启程团队展示可拆卸支架原型，同尺寸材料成本低于对照方案

10月8日，启程团队展示可拆卸支架原型。同一尺寸下，原型材料成本为500元，对照方案为900元。

在李老师指导下，3名学生完成结构校核相关的卡扣修改与台架复测。8千克载荷下的20轮测试中，仍有1轮接头松动；12千克载荷测试尚未完成。团队计划下学期在校内实训中试用该原型。

### 复核与修订

人工对照发现，“完成结构校核相关的卡扣修改”把老师指导的校核与学生完成的工作连得过紧，存在贡献归属不清。第二段改为：

李老师指导结构校核，3名学生完成卡扣修改与台架复测。8千克载荷下的20轮测试中，仍有1轮接头松动；12千克载荷测试尚未完成。团队计划下学期在校内实训中试用该原型。

成本只比较材料费用，不写整机总成本或量产售价；同尺寸条件、松动与未完成状态均保留。反防御让优势先呈现，不授权删除负面结果。发现问题并修订是验收的一部分，不能把初稿含混说成首次全部通过。

## 复测记录建议

在新对话中仅提供技能和对应输入，保存原始输出；人工先核硬性失败，再标记重复、主线或语气问题。模型、宿主、日期和是否读了参考答案分别记录。出现问题时先修该场景对应规则，再用原题与一个同类新题复测。题包检验具体任务，不用样本总数作为质量结论。
