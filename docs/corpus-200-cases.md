# 200篇资料版的场景演练

2026年10月24日，3.0.0版新增12题，连此前40题共52题。素材均为虚构。由当前模型完成试写与逐项复核，未作独立盲测、无技能对照或DSH/WorkBuddy自身模型运行。样本规模不是写作效果分数。

新增资料发现标题与正文数字不同、受理与试验许可分阶段、拟立项仍在公示等问题，本组把它们转成写稿情境。S12初稿把笼统指导具体化为设计，已改回原职责；S8逐字对照只修一处错字。其余逐题看事实与任务，没有按固定措辞评分。

## S1：数字相互冲突，先诊断再写

### 输入

先指出问题，再写能用的短讯，没有更多材料。旭川团队校赛战报标题写4金5银，正文写4金7银6铜、共19项。三处都指同一届同一范围，没有名单；确定的是6月12日参加校赛，王老师指导，成员林书负责汇报。

### 复核后成稿

问题：标题与正文的银奖数不同，正文4＋7＋6＝17，与总数19也不一致。4项金奖是两处一致的信息，其余数量需核对。

旭川团队在校赛获4项金奖

6月12日，旭川团队参加校赛，获得4项金奖等多项金银铜奖。项目由王老师指导，林书负责汇报。

### 核对

正文只采用一致的金奖数及确定的参与事实，不把17自动认定为最终总数；核查说明放在正文外。
